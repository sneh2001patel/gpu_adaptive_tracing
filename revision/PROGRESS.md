## Evidence status

Real L4 telemetry, native CUDA capture, persistent-serving smoke checks and the corrected 18-run engineering matrix have passed their bounded checks. The next study is specified in [the draft protocol](protocol/L4_EXPERIMENT_PROTOCOL.md); its compiled design is not an executable or frozen GPU experiment. Passing unit tests establish code behavior, not diagnostic accuracy. The live classifier currently abstains, and active capture boundaries remain unmeasured. Step 022 passes bounded owned reset/capture feasibility only; it does not validate classification, feature cohort mapping or the main study. Existing paper results were generated under earlier semantics and require audit/regeneration before reuse. Synthetic stress replay remains synthetic.

CPU simulation is a development environment, not an experimental hardware baseline. `HealthyBaseline` is a latency calibration reference; eventual profiling baselines must use the same GPU serving workload as the proposed controller.
